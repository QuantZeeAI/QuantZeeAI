## What we build

QuantZee is a toolkit of premium, original TradingView indicators — adaptive RSI, trend-following, and oscillator tools built to help traders read price action and market structure more clearly. Every indicator in the suite is written from scratch (no re-skinned open-source scripts) and designed to work together as one cohesive toolkit rather than a grab-bag of one-off tools.

The suite covers:
- **Trend tools** — adaptive trend/SuperTrend-style overlays
- **Oscillators** — adaptive RSI with divergence detection and multi-timeframe dashboards
- **Market structure toolkits** — smart-money-concept style tools for structure and liquidity

Pricing and the full current indicator catalog are at **[quantzee.com](https://quantzee.com/)**.

## Open source here

This org hosts open-sourced and retired indicators from the QuantZee suite, released publicly for the community. Current repos:

- **[QuantZee-RSI-Pro-Indicator](https://github.com/QuantZeeAI/QuantZee-RSI-Pro-Indicator)** — RSI Pro+: adaptive OB/OS bands, auto divergence detection, and a multi-timeframe RSI dashboard in one script.
